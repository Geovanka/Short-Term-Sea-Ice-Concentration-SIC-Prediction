# Short-Term-Sea-Ice-Concentration-SIC-Prediction
This is a source code for the research paper "Short-Term Sea Ice Forecasting with Ensemble Model Based on Causal Environmental Analysis "

Dataset for daily sea ice concentration can be accessed [here](https://nsidc.org/data/seaice_index/data-and-image-archive)

Dataset for daily environmental variables can be accessed [here](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels?tab=overview)
